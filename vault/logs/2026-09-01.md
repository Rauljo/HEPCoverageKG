# 2026-09-01 — embeddings, a dead critic, and a night of arms that mostly cannot be read

## Happened

**Encoder sweep, 12 models.** Bigger does not help: dimension-vs-separation
r = +0.065, every 1024-dim model NEGATIVE on the Higgs discrimination, and
`all-roberta-large-v1` (same recipe as mpnet, 1024 vs 768) scores WORSE. The
cause is the tokenizer: bge-base has no `Higgs` token and splits it into
`hi` + `##ggs`, so the word is destroyed before any dimension sees it. PhysBERT
(arXiv-pretrained, same 30,522 vocab size) keeps `Higgs`, `boson`, `quark`,
`luminosity`, `calorimeter` whole and scores best on the Higgs case. See D-087.

**The encoder DOES improve retrieval — I reported otherwise and was wrong.**
On `Higgs candidate`, bge-base returns `lepton/W/proton/photon candidate` at
ranks 5-9; chATLAS returns zero cross-particle contamination; PhysBERT is the
only model that surfaces `h candidate` at all. All three are identical at ranks
1-3, which is why end-to-end F1 could not see it.

**And the encoder was tested with its effect switched off.** `--search-sets`
sets SET_CAP=400; without it retrieval stops at 20 and the model pastes ~3 ids.
Every encoder arm ran plain `--system free-sql`. The user spotted this.

**Six QwQ arms ran with `--critic` set and no critic alive** — 404 on every
judge call, 0 successes in 118 attempts (D-088). Reran; `--subgoal-status`
flipped from +0.042 to -0.065 (D-090). A reported finding ("the critic makes no
F1 difference on QwQ") was the bug, not a result.

**~40 arms across 14 scripts, unreadable.** Code changed four times mid-night;
the free-SQL baseline read 0.592 / 0.526 / 0.473 / 0.465. D-089.

## Decided

- D-087 encoder: tokenizer not capacity; retrieval improves, F1 blind to it.
- D-088 assert the CONFIGURATION, not the connection.
- D-089 five-rule batch protocol; control first AND last.
- D-090 subgoal-status is critic-dependent; four readings, no claim yet.

## Fixed

`KIND_SEMANTICS` flag (was in the frozen path); `ALIASES_EMBED_MODEL` +
`KIND_SEMANTICS` recorded in `_ENV_CONFIG`; **free-SQL recorded NO environment
at all, ever** -- one shared `env_config()` now; empty env var no longer beats
the default (killed 4 jobs in 9s); embedding cache keyed on the ENCODER and
written ATOMICALLY (concurrent arms shared one path, non-atomic savez).
853 tests pass.

## The one thing that survived cleanly

`--index-values`, typed: control 0.378 -> **0.512** (+0.134), same script, same
code, precision AND recall both up. Four of four positive across contexts.
