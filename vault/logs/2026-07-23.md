**New findings (→ folded into the onboarding report as §2.7, §2.8, Q8–9, and a Sunny section)**:
- **QA coverage is very uneven by family.** `predicate_typing` = 2,432 of 3,372 findings and
  barely touches `samples_backgrounds`(2,502 assertions)/`systematics_statistics`(1,512) — the
  only samples rule fires 11× total. **~4,000 assertions carry almost no automated scrutiny.**
  → **flag rates are NOT a cross-family quality measure** (they track scrutiny, not correctness);
  `samples_backgrounds` quality is *unknown*, not good or bad. Correctness isn't measured anywhere
  in this data — settling it needs sampled human judgement (Sunny's thread).
- **Extraction retries**: 137 first-try failures (samples_backgrounds 50/60 = 83%), but **zero
  data lost** — all recovered on retry. Format fragility, not correctness; likely output-size
  driven (failed-then-retried papers average *more* assertions: 42.7 vs 36.9). Same root cause as
  the empty signatures → strengthens the guided-decoding proposal.
- **Method note worth keeping**: three times now a striking number shrank or reversed under one
  more level of checking (energy "contradictions", the retry rate, the flag rates). Ask what a
  number *measures* before believing it — load-bearing for a dissertation claiming "nobody has
  measured X".
